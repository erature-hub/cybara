# Cybara Browser Bridge

Chrome MV3 extension that lets local Cybara agents work in the tabs you share, with your own
signed-in sessions. Load this folder with **Load unpacked** on `chrome://extensions`, then paste
the pairing token from Cybara → Settings → Browser → Browser extension into the toolbar popup.

See [docs/browser-extension.md](../../docs/browser-extension.md) for usage and the security model.
